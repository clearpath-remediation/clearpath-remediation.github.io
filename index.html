Our specialty

PDF accessibility remediation, done by hand

Automated checkers miss many real-world PDF barriers. We remediate in Adobe Acrobat Pro and verify with PAC (PDF Accessibility Checker) and a screen reader, so the result works for people, not just the scanner.

  • Tag structure & reading order

    Correct headings, lists, paragraphs, and a logical reading order that matches the visual layout.

  • Data tables

    Header cells, scope, and complex multi-level tables that read cell by cell in JAWS and NVDA.

  • Fillable forms

    Labeled fields, tooltips, tab order, and error-friendly forms for permits, applications, and registrations.

  • Alt text & charts

    Meaningful alternative text for images, maps, and charts, with long descriptions where a chart carries data.

  • Scanned documents

    OCR, text correction, and full tagging so scanned minutes and archives become searchable and readable.

  • Metadata & language

    Document title, language, bookmarks, and PDF/UA identifiers set so the file passes PAC and Acrobat checks.
